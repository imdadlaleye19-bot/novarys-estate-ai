# Estate AI Showcase

Tu es un Product Designer senior, UX/UI designer et développeur full-stack spécialisé dans les plateformes SaaS immobilières premium.

Je veux que tu construises un prototype DEMO complet, réaliste et très haut de gamme d'une plateforme appelée :

NOVARYS ESTATE

Tagline :
"Transform your real estate business with AI."

OBJECTIF DU PROJET

Cette plateforme sera utilisée par NOVARYS pour faire des démonstrations commerciales auprès d'agences immobilières, promoteurs et gestionnaires de biens en Afrique francophone, notamment en Côte d'Ivoire, au Sénégal et au Bénin.

IMPORTANT :
Ce prototype doit donner l'impression d'un véritable produit SaaS déjà commercialisable.

Ce n'est PAS une simple landing page.
Je veux une démonstration interactive complète montrant comment une agence immobilière peut :

1. présenter ses biens ;
2. permettre aux visiteurs de rechercher un bien ;
3. utiliser un assistant IA pour trouver le bien correspondant à leurs critères ;
4. qualifier automatiquement les prospects ;
5. transmettre les prospects à l'équipe commerciale ;
6. suivre les prospects dans un pipeline ;
7. analyser les performances commerciales.

DESIGN

Créer une interface :
- premium
- moderne
- minimaliste
- élégante
- crédible
- adaptée à l'immobilier haut de gamme
- responsive desktop/tablette/mobile
- excellente UX
- animations discrètes et fluides
- beaucoup d'espace blanc
- typographie moderne
- cartes élégantes
- micro-interactions
- transitions fluides

Éviter absolument :
- design générique de template
- couleurs criardes
- interface ressemblant à un projet étudiant
- surcharge visuelle
- éléments inutiles

Utiliser une identité visuelle premium pour NOVARYS.

Le produit doit avoir une apparence comparable à un SaaS moderne haut de gamme.
